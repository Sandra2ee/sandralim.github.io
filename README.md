# Simple Website Starter

This folder contains a very simple local website that is easy to edit.

## How to use it

1. Open the folder in VS Code.
2. Open index.html in your browser.
3. Edit the content in script.js to change the text.
4. Edit styles.css to change colors and layout.
5. Add more sections in index.html if you want.

## Quick start

You can also start a simple local server from this folder:

```bash
cd /Users/sandralimair/website-starter
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.
